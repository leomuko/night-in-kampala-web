# Standalone development images

These four assets are AI-generated placeholders created with the built-in image tool. They are separate images for the future homepage, not flattened website boards or photographs of real Night in Kampala stock. They do not establish the final garment/art direction.

The owner authorised generated placeholders in the pre-build review. Each file is named as a placeholder, and [manifest.json](manifest.json) records that status, dimensions and checksums. When used in the application, show the visible label **AI-generated placeholder**, use descriptive alt text identifying illustrative content, and keep these fixtures out of real purchasable inventory. Filename/alt text alone does not replace the visible label. Replace with owner-supplied photography before public catalogue publication.
